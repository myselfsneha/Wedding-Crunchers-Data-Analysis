## ✿ The story starts here

Weddings are emotional. Weddings are elaborate. Weddings can also get *really* expensive.

Between venues, catering, guest lists, locations, and seasonal choices, there's a surprising amount of data hiding behind the celebrations.

**Wedding Crunchers** is a Python-based Exploratory Data Analysis (EDA) project that looks beyond the pretty picture to investigate the numbers behind wedding expenses.

The idea is simple: take a dataset, ask better questions, find patterns, and turn raw numbers into a story worth understanding.

Because yes, even love has a spreadsheet somewhere. 😭💸

## 🚀 Want to run the investigation yourself?

No fancy setup required — just Python and a few libraries.

### 1. Clone the repository

```bash
git clone https://github.com/myselfsneha/Wedding-Crunchers-Data-Analysis.git
cd Wedding-Crunchers-Data-Analysis
```

### 2. Install the libraries

```bash
pip install pandas numpy matplotlib seaborn geopandas jupyter
```

### 3. Open the notebook

```bash
jupyter notebook
```

Open `Wedding-Crunchers-Data-Analysis.ipynb` and run the cells to explore the analysis.

**Before running:** make sure `wedding_data.csv` is in the location expected by the notebook. If the dataset path differs, update the relevant cell to match your local setup.
