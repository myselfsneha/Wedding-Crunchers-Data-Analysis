## ✿ The idea behind the project

Weddings are full of big decisions — venues, catering, guest lists, locations, and budgets.

But what happens when we look beyond the celebrations and explore the numbers behind them?

**Wedding Crunchers** is a Python-based exploratory data analysis project that dives into wedding industry data to uncover patterns in costs, guest counts, seasonal trends, and geographic differences.

Think of it as a little data investigation into the business of weddings — because even the most beautiful celebrations leave behind some interesting numbers. 📊

## ♡ What we're exploring

| Area | What's inside |
|---|---|
| 🧹 Data preparation | Cleaning, missing values, preprocessing, and feature engineering |
| 💸 Wedding economics | Cost distributions, spending patterns, and cost comparisons |
| 👥 Guest counts | Exploring how guest numbers relate to overall wedding expenses |
| 🌦️ Seasonal patterns | Looking at changes in wedding costs across seasons |
| 📍 Geographic analysis | Comparing cities, metro and non-metro regions, and spatial patterns |
| 🔗 Statistical relationships | Correlations, heatmaps, and relationships between numerical variables |
| 🗺️ Geospatial visualization | Using GeoPandas to explore location-based patterns |

## 📖 A peek at the findings

The current analysis highlights a few interesting patterns:

- **Venue & catering:** These emerge as major contributors to wedding expenses.
- **Location matters:** Wedding costs vary across cities and geographic areas.
- **More guests, more spending:** Guest count shows a strong positive relationship with total wedding cost.
- **Metro vs. non-metro:** Metro cities show higher average costs per guest in the current analysis.
- **Urban premium weddings:** Higher-budget weddings appear more concentrated in urban areas.

These observations come from the project's existing analysis and are best interpreted within the dataset's scope — not as universal rules for every wedding.

## 🚀 Run it yourself

Want to explore the analysis? Here's how to get started.

**1. Clone the repository**

```bash
git clone https://github.com/myselfsneha/Wedding-Crunchers-Data-Analysis.git
cd Wedding-Crunchers-Data-Analysis
```

**2. Install the required libraries**

```bash
pip install pandas numpy matplotlib seaborn geopandas jupyter
```

**3. Launch Jupyter Notebook**

```bash
jupyter notebook
```

Open `Wedding-Crunchers-Data-Analysis.ipynb` and run the cells to follow the analysis.

*Note: The dataset is expected to be available at the path referenced by the notebook. If a cell uses a different file path, adjust it to match the location of `wedding_data.csv`.*
